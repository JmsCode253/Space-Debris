# Space-Debris
•	Developing an open-source simulation that aims to reduce the number of space debris in Earth’s low orbit, modeling 50 objects extracted from current NASA HBR Debris estimates.
•	Programming a device that detects and performs avoidance procedures for object shapes outside its scope. Object continuously loops, with debris publisher monitoring 50 obj per 150 seconds.
•	Designing a logic system to determine manageable debris sizes and complete full mission simulations 
•	Applied high-level C++ and Python concepts in the process, object-oriented design, and simulation testing in ROS2 and other software.
